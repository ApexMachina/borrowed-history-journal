# Borrowed History Journal

Write a claim. Tag its source:

- **Deduction**
- **Direct Experience / Intuition**
- **Borrowed History**

See the composition. Entries stay on this device.

Framework: [*The Borrowed History Predicament*](https://twocentphilosophy.com/products/the-borrowed-history-predicament)

## Deploy

1. Import this repo on [Vercel](https://vercel.com)
2. Deploy
3. Optional: add `journal.twocentphilosophy.com` in Domains + CNAME in DNS

## Local

```bash
npm install
npm run dev
```
